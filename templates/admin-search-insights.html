How to read this

Relational search matches characters. A review only appears if it literally contains the typed string, and results come back unranked.

Vector search compares meaning. Each review is stored as a 384-dimension embedding, and the query returns its nearest neighbours by cosine distance — so a review about "remote meetings" surfaces for "somewhere to work" despite sharing no words. The percentage is relative closeness, not a confidence score.
